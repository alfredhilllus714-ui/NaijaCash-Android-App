# NaijaCash Android project

This repository contains a snapshot of the NaijaCash AppDeploy web app source under `appdeploy-source/`.

Live app: https://naijacash-14ydi7.v2.appdeploy.ai/

The current app is a React/Vite marketplace and its sign-in, listings and AI APIs use AppDeploy services. The Android package will be prepared as a mobile WebView wrapper around the live app, so it requires an internet connection and the AppDeploy service to remain available.

This source snapshot is preserved for reference. It is not yet a standalone Android APK build.
